# Colaqui

Aplicativo pessoal para cadastrar uma coisa usada uma única vez e preparar sua venda em vários canais.

## Estado atual

A branch `feature/colaqui-001` implementa a fundação, autenticação de proprietário, catálogo, PostgreSQL/Prisma e fotos em MinIO/S3.

O desenho aprovado está em `docs/superpowers/specs/2026-10-29-colaqui-design.md` e o plano da branch em `docs/superpowers/plans/2026-10-29-colaqui-001-foundation-catalog.md`.
